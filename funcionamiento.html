¿Cómo funciona?

El atacante puede ver todo lo que se envía en ambas direcciones: contraseñas, mensajes, cookies, datos bancarios, etc.

  • El atacante se posiciona entre la víctima y el servidor.
  • Intercepta la comunicación para robar datos o alterar mensajes.
  • Las víctimas creen que están comunicándose de forma segura.
